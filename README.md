# Group5_CurrencyConverter
Java-based Currency Converter that converts between multiple currencies using real-time or predefined exchange rates.

This Java program demonstrates the use of HashMaps, static initializers, and user input handling in Java.

A class CurrencyConverter is created with two HashMap collections — one for storing exchange rates relative to USD and another for storing currency names.

## The program allows the user to:

* Choose a source and target currency

* Enter an amount to convert

* View the converted result with the corresponding currency names

* This simulates a real-world currency converter application where exchange rate data is stored and used to calculate currency conversions interactively.
